# StudyTube — Design System

## 1. Design Philosophy

StudyTube should feel like a carefully crafted productivity utility, not an AI product.

Design direction:
- Minimalism.
- Restrained glassmorphism.
- Functional visual hierarchy.
- Clean typography.
- Subtle depth.
- No unnecessary decoration.

## 2. Visual Restrictions

DO NOT USE:
- Purple or blue AI gradients.
- AI-generated-looking dashboard layouts.
- Generic AI sparkles.
- Chatbot icons.
- Excessive rounded cards.
- Decorative charts.
- Unnecessary animations.
- Gradient-filled backgrounds.
- Overly colorful dashboards.

## 3. Color Palette

Primary:
- Background: #F7F7F5
- Surface: #FFFFFF
- Text: #171717
- Secondary text: #737373
- Border: #E5E5E5

Accent:
- Focus Green: #2F6B4F
- Focus Green Light: #E7F0E9
- Warning: #C58B36
- Error: #B84646

Dark Mode:
- Background: #151515
- Surface: #202020
- Text: #F5F5F5
- Border: #343434

## 4. Typography

Preferred:
- Inter
- Geist
- System UI

Use:
- Clear typography hierarchy.
- Compact labels.
- Comfortable readability.
- No oversized marketing typography inside the popup.

## 5. Glassmorphism

Glassmorphism is reserved for:
- Focus Mode toggle.
- Active focus status surface.
- Optional timer overlay.

Implementation:
- Translucent neutral surface.
- Subtle backdrop blur.
- Thin border.
- Soft shadow.
- No colored gradient.
- No excessive transparency.

Glass must improve visual hierarchy, not reduce readability.

## 6. Popup Layout

1. Logo and product name.
2. Focus Mode toggle.
3. Timer.
4. Session controls.
5. Filtering status.
6. Minimal settings access.

## 7. Interaction Design

- Toggle changes state immediately.
- Clear active/inactive states.
- Small transitions.
- Keyboard accessibility.
- Visible focus indicators.
- Reduced motion support.

## 8. Iconography

Use conventional icons from Lucide or another consistent icon library.

Avoid AI symbols and decorative icons.

Icons must communicate functionality:
- Timer.
- Settings.
- Shield.
- Play.
- Pause.
- Check.
- Block.

## 9. Responsive Behavior

The popup must fit standard browser extension dimensions.

The design should remain usable without scrolling under normal conditions.
